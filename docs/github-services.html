GitHub サービス

個人開発で使っている GitHub の 9 サービスを、開発の流れに沿って整理したリファレンス

ざっくり言うと
  • 計画 → 開発 → 検査・自動化 → 配布・公開 の順に並べると、9 サービスの役割が整理しやすい
  • 中心は Actions。テスト・セキュリティ検査・デプロイ・リリースをつなぐ自動化の土台になる
  • 配布先は中身で選ぶ: ライブラリやイメージは Packages、バイナリは Releases、Web サイトは Pages
