UI デザインスタイル早見表

スキューモフィズムからリキッドグラスまで、実物サンプルと CSS で見比べる

ざっくり言うと
  • UI の流行は「本物っぽい立体」と「平面でシンプル」の間を振り子のように行き来している。
  • 違いの正体はほぼ 影・光・質感（透明度）をどう使うか。CSS で言えば box-shadow・gradient・backdrop-filter の使い方の差。
  • 見た目の好みだけでなく、押せる場所がわかるか（アフォーダンス）とコントラスト（アクセシビリティ）で選ぶのが大事。

立体 ↔ 平面のスペクトラム

◀ 立体・質感あり（現実の模倣）平面・記号的 ▶
1スキューモフィズム 2クレイモーフィズム 3ニューモーフィズム 4リキッドグラス 5グラスモーフィズム 6マテリアル 7フラット 2.0 8ネオブルータリズム 9フラット

※ 並びは「影や質感の強さ」の目安。ネオブルータリズムは影を使うがぼかさない「記号としての影」なので平面寄り。

スタイル別の特徴と CSS

Button

スキューモフィズム (Skeuomorphism)

最盛期: 〜2012代表: iOS 6 以前, 初期 macOS

革・木目・紙・金属など現実の素材や道具を忠実に模倣する手法。メモ帳アプリが黄色い罫線ノート、本棚アプリが木の棚、といった具合。タッチ操作が新しかった時代に「これは押せる／めくれる」と直感させる役割があった。

◯ 強み
  • 操作方法が直感的
  • 高級感・温かみ
△ 弱み
  • 装飾が重く情報が埋もれる
  • 画像素材が多く制作・保守コスト大
.btn {
  background: linear-gradient(#7fc4ff, #2a7fd4 55%, #1f6bbd); /* 光沢 */
  border: 1px solid #154c8a;
  box-shadow: inset 0 1px 0 rgba(255,255,255,.6), /* 上辺のハイライト */
              0 2px 3px rgba(0,0,0,.45);         /* 落ち影 */
  text-shadow: 0 -1px 0 rgba(0,0,0,.4);           /* 刻印風の文字 */
}
Button

フラットデザイン (Flat Design)

登場: 2012〜2013代表: Windows 8 (Metro), iOS 7

グラデーション・影・質感をすべて取り除き、単色の面・タイポグラフィ・アイコンだけで構成する。スキューモフィズムへの反動として広まり、レスポンシブ対応や軽量化とも相性が良かった。

◯ 強み
  • 軽量・高速、スケールしやすい
  • 情報がすっきり読みやすい
△ 弱み
  • ボタンとただの色面の区別がつきにくい
  • どのアプリも似た見た目に
.btn {
  background: #e74c3c;  /* 単色ベタ塗り */
  color: #fff;
  border: none;
  border-radius: 0;     /* 角丸も影もなし */
}
Button

フラット 2.0 / セミフラット (Semi-flat)

2014〜現在代表: 今の多くの Web サービス

フラットの弱点だった「押せるかわからない」を補うため、ごく控えめな影・角丸・グラデーションを戻したもの。現在の Web UI の大半はこの考え方がベース。

◯ 強み
  • シンプルさと操作性のバランスが良い
  • 流行に左右されにくい
△ 弱み
  • 個性は出しにくい
  • 「無難」止まりになりがち
.btn {
  background: #3b82f6;
  border-radius: 6px;                          /* 少しだけ角丸 */
  box-shadow: 0 2px 6px rgba(59,130,246,.35); /* 薄い影で浮きを示す */
}

マテリアルデザイン (Material Design)

発表: 2014 (Google I/O)代表: Android, Google 各サービス

「紙とインク」をメタファーにしたフラットベースの体系。UI 要素を厚みのない紙のシートと見なし、重なり順を高さ（エレベーション, elevation）＝影の濃さで表す。操作時の波紋（リップル）など、動き（モーション）にも意味を持たせる。単なる見た目ではなくガイドライン付きのデザインシステムである点が特徴。

◯ 強み
  • 階層が影で一目でわかる
  • 仕様・コンポーネントが網羅的
△ 弱み
  • そのまま使うと「Google っぽさ」が強い
  • ルールが多く学習コストあり
/* elevation は段階的な影で表現する */
.card   { box-shadow: 0 1px 3px rgba(0,0,0,.12), 0 1px 2px rgba(0,0,0,.24); } /* 低い */
.dialog { box-shadow: 0 10px 20px rgba(0,0,0,.19), 0 6px 6px rgba(0,0,0,.23); } /* 高い */
.fab    { border-radius: 50%; box-shadow: 0 4px 8px rgba(0,0,0,.3); }

Material You / Material 3

2021〜 (Android 12)2025: M3 Expressive (Android 16)

マテリアルの第 3 世代。壁紙などから配色を自動生成するダイナミックカラー、大きな角丸、影より色の濃淡（トーン）で階層を表すのが特徴。2025 年の「Expressive」では形状や動きの表現がさらに豊かになった。

◯ 強み
  • ユーザーごとにパーソナライズ
  • トークンで配色を体系管理
△ 弱み
  • 自動配色はブランド色と衝突しやすい
  • 初代マテリアルとは別物と考えるべき
:root { --md-primary: #6750a4; --md-secondary-container: #e8def8; }
.btn  { background: var(--md-primary); border-radius: 999px; /* ピル型 */ }
.chip { background: var(--md-secondary-container); border-radius: 8px; }
/* 影ではなく「面の色トーン」で浮きを表すのが M3 流 */

ニューモーフィズム (Neumorphism / Soft UI)

流行: 2019 末〜2020出どころ: Dribbble の銀行アプリ案

New + Skeuomorphism の造語（2019 年に命名）。Oleksandr Plyuto が Dribbble に投稿した銀行アプリのモックがきっかけで広まった。背景と同じ色の要素に、左上へ明るい影・右下へ暗い影を付けて、背景から押し出された（または凹んだ）ように見せる。柔らかいプラスチック成形のような質感。

◯ 強み
  • 上品で柔らかな印象
  • CSS だけで再現できる
△ 弱み
  • コントラストが極端に低くアクセシビリティ的に厳しい
  • 押した／押してない状態の区別が弱い
.neu {
  background: #e0e5ec;                  /* 背景と同じ色 */
  border-radius: 18px;
  box-shadow:  8px  8px 16px #a3b1c6,   /* 右下に暗い影 */
              -8px -8px 16px #ffffff;   /* 左上に明るい影 */
}
.neu.pressed { box-shadow: inset 6px 6px 12px #a3b1c6, inset -6px -6px 12px #fff; }

グラスモーフィズム (Glassmorphism)

流行: 2020〜代表: macOS Big Sur, Windows 11 (Mica/Acrylic)

すりガラス越しに背景がぼやけて見える半透明パネル。背後の色が透けることで奥行きと「今どの画面の上にいるか」の文脈が伝わる。祖先には Windows Vista の Aero や iOS 7 のぼかしがある。

◯ 強み
  • 奥行きがあり華やか
  • 背景の文脈を残せる
△ 弱み
  • 背景次第で文字が読めなくなる
  • blur は描画負荷が高い
.glass {
  background: rgba(255,255,255,.18);           /* 半透明 */
  backdrop-filter: blur(12px);                 /* 背後をぼかす（主役） */
  -webkit-backdrop-filter: blur(12px);
  border: 1px solid rgba(255,255,255,.45);     /* ガラスのフチ */
  border-radius: 14px;
}
/* 背景がカラフルでないと効果が出ない点に注意 */

リキッドグラス (Liquid Glass)

発表: 2025 (WWDC)代表: iOS 26 / macOS Tahoe など

Apple が全 OS 共通で採用した新しい素材表現。グラスモーフィズムの「ぼかし」に加えて、レンズのような屈折・縁の光の反射・動きに応じたゆらぎを持つ。コンテンツの上に浮かぶナビゲーション層に使い、内容そのものはフラットに保つ使い分けが前提。

◯ 強み
  • 生き物のような立体感・動き
  • コンテンツ領域を広く使える
△ 弱み
  • 可読性への批判が多く、iOS 26.1 でガラス感を抑える「色付き」表示が追加された
  • Web で完全再現は難しい（屈折は SVG フィルタ等が必要）
/* CSS での「雰囲気」再現。本物の屈折表現は SVG feDisplacementMap などが必要 */
.liquid {
  background: rgba(255,255,255,.12);
  backdrop-filter: blur(4px) saturate(1.8);   /* 弱めのぼかし＋彩度アップ */
  box-shadow: inset 0 1px 1px rgba(255,255,255,.9),   /* 縁のハイライト */
              inset 0 0 12px rgba(255,255,255,.25),   /* 内側の光 */
              0 6px 18px rgba(0,0,0,.18);
  border-radius: 999px;
}

クレイモーフィズム (Claymorphism)

流行: 2021〜3D イラストと相性◎

粘土のようにぷっくり膨らんだ見た目。大きな角丸、パステルカラー、内側の影（inset）を 2 方向＋外側に柔らかい影。ニューモーフィズムと違い、要素にはっきりした色があるのでまだ視認性が保てる。

◯ 強み
  • 親しみやすくポップ
  • 子ども向け・LP で映える
△ 弱み
  • 業務系・情報量の多い画面には不向き
  • 幼い印象になりやすい
.clay {
  background: #c4b5fd;
  border-radius: 26px;
  box-shadow: inset -6px -6px 12px rgba(0,0,0,.15),     /* 内側の暗部 */
              inset  6px  6px 12px rgba(255,255,255,.6), /* 内側の明部 */
              8px 10px 18px rgba(124,58,237,.3);         /* 外側の影 */
}

ネオブルータリズム (Neo-brutalism)

流行: 2020 年代〜代表: Gumroad など

建築のブルータリズムに由来。太い黒枠・ぼかさないベタの影・原色・荒々しいタイポグラフィで、あえて「洗練されていない」強さを出す。洗練されすぎて画一的になった UI への反動。

◯ 強み
  • 一目で覚えられる強い個性
  • コントラストが高く読みやすい
△ 弱み
  • 好みが極端に分かれる
  • 雑に見えるリスク
.brutal {
  background: #ff90e8;
  border: 3px solid #000;      /* 太い黒枠 */
  box-shadow: 5px 5px 0 #000;  /* ぼかし 0 のベタ影 */
  border-radius: 0;
}
.brutal:active { transform: translate(5px,5px); box-shadow: none; } /* 押すと沈む */

年表：立体と平面の振り子

  • 2001〜macOS Aqua：水滴のようなツヤのボタン立体
  • 2007iPhone 登場、Windows Vista Aero（半透明ガラス）立体
  • 2010〜iOS のスキューモフィズムが最盛期（革・木目・紙）立体
  • 2012Windows 8（Metro）でタイル型フラット UI平面
  • 2013iOS 7 がフラットへ大転換（ただし背景ぼかしは導入）平面
  • 2014Google がマテリアルデザインを発表平面＋影
  • 2017Microsoft Fluent Design（Acrylic＝すりガラス素材）
  • 2019〜20ニューモーフィズムが Dribbble で話題に立体
  • 2020macOS Big Sur。Michal Malewicz が「グラスモーフィズム」と命名立体
  • 2021Material You（M3）、Windows 11（Mica）。前後して Web ではクレイ／ネオブルータリズムも流行
  • 2025Google「Material 3 Expressive」（5 月）、Apple「Liquid Glass」（6 月 WWDC）立体・動き

流れとしては「現実の模倣 → 記号化（フラット）→ 意味のある奥行きを少しずつ戻す」。最近は「素材」そのものより光と動きで立体感を出す方向。

よくある誤解

✕ マテリアルデザイン ＝ フラットデザインの一種

半分正解。見た目はフラット寄りだが、影で高さを表す点、そして色・余白・動きまで決めたデザインシステム（ガイドライン）である点が単なるフラットと違う。

✕ グラスモーフィズムは「半透明にすればいい」

主役は透明度ではなく背景のぼかし（backdrop-filter）。さらにカラフルな背景がないとガラス感は出ない。白背景の上に置いても効果はほぼゼロ。

✕ ニューモーフィズムは次の主流になる

コントラスト不足でWCAG の基準を満たしにくく、実用 UI には広まらなかった。小さな部品にアクセントとして使う程度が現実的。

✕ スキューモフィズムは完全に死んだ

アイコンの立体感、ゴミ箱やフロッピーの「保存」アイコンなど、メタファーとしては今も生きている。リキッドグラスも「現実の素材の振る舞い」を模す点でスキューモフィズムの系譜にある。

✕ どれか 1 つを選んで全画面に統一すべき

実際は混ぜて使う。例：コンテンツはフラット 2.0、上に浮くナビやモーダルだけグラス、という層ごとの使い分けが一般的。
