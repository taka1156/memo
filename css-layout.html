CSS レイアウト

「1 列に並べる」は Flex、「縦横の格子に置く」は Grid。あとは部品が自分の幅で決まるか

ざっくり言うと
  • Flexbox は 1 方向に並べて、余った空間を分け合う。中身の大きさが主役（ナビ、ボタン列、カードの中身）。
  • Grid は縦横の格子を先に決めて、そこに置く。枠が主役（ページ全体、カード一覧、フォーム）。
  • 部品の見た目は画面幅ではなく置かれた場所の幅で変えたい → コンテナクエリ。CSS の上書き合戦はカスケードレイヤーで順位を明示して止める。

どっちを使う？

  

    

      
やりたいこと選ぶもの書き方

      
上下左右の中央寄せGriddisplay:grid; place-items:center

      
ナビの左にロゴ、右にメニューFlexdisplay:flex; justify-content:space-between

      
ロゴは左、メニューとボタンはまとめて右Flex右に寄せたい最初の要素に margin-left:auto（余りを全部その左に入れる）

      
カードを入るだけ並べて自動で折り返すGridgrid-template-columns: repeat(auto-fill, minmax(220px, 1fr))

      
フッターを画面下に固定（中身が少なくても）Gridmin-height:100dvh; grid-template-rows: auto 1fr auto

      
タグを並べて折り返す（幅はまちまち）Flexdisplay:flex; flex-wrap:wrap; gap:6px

並んだカードのタイトル・本文の高さを揃えるGrid + subgridカードを grid-row: span 3; grid-template-rows: subgrid

    

  

  
auto-fill は列を作れるだけ作る（空列も残る）、auto-fit は空列を潰して既存の列を伸ばす。アイテムが少ないときに差が出る。


  
コンテナクエリ

  

    
右下の角をドラッグして枠の幅を変えると、カードが自分の置き場所の幅で横並びに切り替わる（画面幅は関係ない）。

    
記事カード
サイドバーに置けば縦、本文に置けば横。同じ部品のまま。


.card-slot { container-type: inline-size; }   /* 親を「測れる箱」にする */
@container (min-width: 380px) {
  .card { grid-template-columns: 140px 1fr; }
}

    
メディアクエリはページのレイアウト（サイドバーを出すか）に、コンテナクエリは部品に使う。コンテナ幅に対する単位 cqi もある（font-size: clamp(1rem, 4cqi, 1.5rem)）。

  


  
どのルールが勝つか（カスケード）

  

    
1オリジン（出どころ）と重要度（ブラウザ既定 < 作者 < 作者の !important）

    
2カスケードレイヤー（@layer で後に宣言した層が勝つ。通常の宣言では、レイヤー外のスタイルがどの層よりも強い（style 属性はさらに上）。ただし !important では順位が逆になり、先に宣言した層が勝つ）

    
3詳細度（ID > クラス・属性・疑似クラス > 要素）

    
4書いた順（後が勝つ）

  


@layer reset, base, components, utilities;   /* 順位をここで宣言 */

@layer components { #nav .link { color: gray; } }   /* 詳細度が高くても */
@layer utilities  { .text-red  { color: red;  } }   /* 後の層が勝つ */

  
外部ライブラリの CSS を @import url(lib.css) layer(vendor); で低い層に入れれば、自分のクラス 1 つで上書きでき、!important 合戦が不要になる。詳細度を上げずに書くには :where()（詳細度 0）が便利。

機能何ができる

      
:has()子や後続の状態で親を選ぶ。.field:has(input:invalid) でエラー時に枠を赤く、JS なし。

      
CSS ネストSass なしで .card { &:hover { … } } と書ける。

      
論理プロパティmargin-inline・padding-block・inset-inline-start。縦書きや右から左の言語でも正しく効く。

      
clamp()font-size: clamp(1rem, 2.5vw, 1.5rem) で最小・最大つきの可変サイズ。

      
dvh / svhスマホのアドレスバーの出入りを考慮した高さ。100vh がはみ出す問題を避ける。

      
aspect-ratio縦横比を保つ。動画の埋め込みや画像の場所取り（CLS 対策）に。

      
View Transitions画面の切り替えをアニメーションでつなぐ。同一ドキュメント内に加え、ページ遷移でも使えるようになってきている。

      
アンカー位置指定（anchor positioning）ツールチップやメニューを、別の要素の位置に合わせて CSS だけで置く。2026 年 1 月の Firefox 147 で主要ブラウザがそろって対応した（Baseline）。古いブラウザも対象なら、代わりの表示を用意する。

    

  


  
よくある誤解

  
Grid が出たから Flexbox はもう要らない
役割が違う。中身の大きさに合わせて 1 列に流す（折り返し位置も中身次第）なら Flex のほうが自然。ページ骨格は Grid、その中の部品は Flex、という組み合わせが普通。

  
margin で間隔を空ける
並びの間隔は親の gap で。子の margin だと先頭・末尾の余計な余白を消す工夫が要る。gap は Flex でも Grid でも使える。

  
z-index を大きくすれば前に出る
z-index は同じ重ね合わせコンテキストの中でしか比べられない。親に transform・opacity < 1・position + z-index などがあると、そこで新しいコンテキストができ、子をいくら大きくしても親の外には勝てない。
